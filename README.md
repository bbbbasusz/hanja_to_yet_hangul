# 한자 → 한글 변환기

한자를 입력하면 **전통 한글 음(音)**으로 바로 변환해 주는 웹 기반 변환기입니다.  
조선시대·중세 한국어 음운을 반영한 표기를 사용하며, 성조 표시(ʟ · ʜ · ʀ)가 함께 나타납니다.

<br>

## 주요 기능

- **실시간 변환** — 한자를 입력하는 즉시 한글로 변환됩니다.
- **성조 표시** — 평성(ʟ), 상성(ʜ), 거성(ʀ) 등 중세 한국어 성조를 함께 표시합니다.
- **한자 사전 내장** — 수천 자의 한자-한글 대응 데이터를 포함하고 있습니다.
- **복사 / 지우기** — 변환 결과를 한 번에 복사하거나 입력창을 비울 수 있습니다.
- **반응형 디자인** — 모바일·데스크톱 모두 사용하기 편리합니다.

<br>

## 사용 방법

1. [여기](https://bbbbasusz.github.io/hanja_to_yet_hangul/)를 누릅니다.
   (별도 서버나 설치가 필요 없습니다.)
2. 상단 입력창에 한자를 입력합니다.  
   예: `韓國`, `天地`, `春夏秋冬`
3. 아래에 변환된 한글이 실시간으로 표시됩니다.
4. **복사** 버튼을 누르면 결과가 클립보드에 복사됩니다.
5. **지우기** 버튼으로 입력창을 초기화할 수 있습니다.

<br>

## 예시

| 입력 (한자) | 변환 결과 (한글) |
|-------------|------------------|
| 天          | 텬ʟ              |
| 地          | 디ʜ              |
| 春          | 츈ʟ              |
| 國          | 국ʜ              |
| 韓國        | 한ʟ국ʜ           |

## 참고

- 변환 결과는 현대 표준 한국어 발음이 아니라, **중세·조선시대 한자음**을 기준으로 한 표기입니다.
- 일부 한자는 사전에 없을 수 있으며, 이 경우 원문 한자가 그대로 표시됩니다.
